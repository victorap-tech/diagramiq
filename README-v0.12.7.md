# DiagramIQ v0.12.7

## Inventario inteligente

- El asistente responde consultas cuantitativas usando el catálogo estructurado, sin depender de OCR ni de una estimación de Claude.
- Ejemplos: “¿Cuántos variadores hay?”, “¿Cuántos motores hay en este sector?”, “¿Cuáles son los contactores?”.
- Respeta los filtros activos de empresa, planta y sector.
- Consolida apariciones repetidas para contar una sola vez cada equipo físico.
- Puede desglosar por fabricante y listar TAG, modelo y sector.
- Mantiene sin cambios el visor HD, la Biblioteca y el asistente técnico documental.
