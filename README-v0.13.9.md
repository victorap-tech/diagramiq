# DiagramIQ v0.13.9

- DiagramIQ Vision compara TAG, modelo, marca, tipo y texto visible contra componentes indexados en PostgreSQL.
- Devuelve hasta 8 coincidencias ordenadas por porcentaje de similitud.
- Respeta empresa, planta y sector seleccionados.
- Muestra las razones del puntaje y permite abrir cada coincidencia directamente en el plano.
- Filtra términos ambiguos como PE, N, 24V y colores de conductores.
