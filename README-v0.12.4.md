# DiagramIQ v0.12.4

Base: v0.12.3.

## Correcciones

- Ficha de motores con datos técnicos estructurados: potencia, tensión, corriente, velocidad, polos, cable y función cuando están presentes en el plano.
- El OCR completo queda dentro de **Texto original del plano**, plegado por defecto.
- El visor usa un contenedor flexible con desplazamiento vertical y horizontal real.
- La barra superior permanece visible y el usuario puede recorrer toda la página sin que el modal recorte la parte inferior.
